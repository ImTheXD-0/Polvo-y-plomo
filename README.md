# Instrucciones para jugar: 
1. Iniciar el ejecutable del juego
2. Desde la pantalla del título, darle al botón central de inicio y tras una cinemática inicial empezará el nivel.
3. Una vez dentro del nivel se desplegará un menú con los controles para teclado y para mando. Para iniciar a jugar cerrar esa pantalla desplegable pulsando el botón central o presionando ESC.
4. Para avanzar en el juego deberás sobrevivir un tiempo estipulado y acabar con todos los enemigos que aparecerán en pantalla. Tras superar el nivel 1, se ejecutará una cinemática que dará transición al nivel final.
5. El último nivel consiste en un enfrentamiento contra un jefe que te irá disparando mientras se esconde y spawnean enemigos. Para pasarte el juego deberás acabar con el jefe.
# Controles para teclado y para mando: 
Moverte - teclas WASD - Joystick izquierdo/Cruceta 
Apuntar arma - Movimiento con el ratón - Joystick derecho
Disparar - Click izquierdo - "RB"
Ataque melee - Click derecho -  "LT"
Recargar - "R"- "X"
Habilidad - "Q" - "B"
Roll - Barra espaciadora - "A"
Pausa - "ESC" - "Options"
